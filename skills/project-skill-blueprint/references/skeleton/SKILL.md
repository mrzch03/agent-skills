## 层级(依赖单向,引用不复制)

元事实(knowledge/lessons/troubleshooting,表格化分领域)← 工作单元(项目指定的任务记录位置（未约定时可用 `issues/`）,bug/需求一事一文件,按项目原稿约定与授权同步)← 交接(handoff.md,只指路)。已有项目文档只引用，不复制。当前规则不依赖临时任务文件；依据可链接稳定归档。

## 目录(你要干什么 → 读哪)
```
knowledge/        元事实或现有原稿引用(概念/架构/契约/环境)
lessons/          heuristics 决策法则 + case-studies 复盘
troubleshooting/  症状→根因索引 + 现成命令
handoff.md        交接(主线指针+在飞清单,完结即删行)
任务记录位置      使用项目实际路径，skill 只放指针
tools/            诊断 CLI
```

## 维护(谁改谁更新)
| 触发 | 更新 |
|---|---|
| 会话开始 | 读 handoff.md(→在飞任务记录)+ 近期改动 |
| 在飞工作有进展/证据 | 写进项目任务记录;handoff.md 只动指针行 |
| 撞到新症状/弯路 | troubleshooting/;可泛化的进 lessons/heuristics.md |
| 有了新的慢变认知 | 项目原稿或 knowledge/ 对应文件；此处引用,不复制 |
| 链路/契约/铁律变更 | 同一工作单元内改完对应文件 |
